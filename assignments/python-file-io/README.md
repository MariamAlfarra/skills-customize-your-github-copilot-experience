# 📘 Assignment: Python Automation with File I/O

## 🎯 Objective

Learn how to read and write files in Python, then use those skills to automate a text processing task.

## 📝 Tasks

### 🛠️ Task 1: Read and summarize a text file

#### Description
Open the provided sample text file, read its contents, and calculate how many lines, words, and characters it contains.

#### Requirements
Completed program should:

- Read `sample-text.txt` from disk
- Count the number of lines, words, and characters in the file
- Print a summary report to the console
- Use functions to organize file reading and counting logic

### 🛠️ Task 2: Write an automated output file

#### Description
Create a new output file that stores the summary data or a transformed version of the original text.

#### Requirements
Completed program should:

- Create a new file named `report.txt` or similar
- Write the summary results or transformed text into the new file
- Use file writing mode safely so the file is created or overwritten
- Confirm the output file contains the expected results
